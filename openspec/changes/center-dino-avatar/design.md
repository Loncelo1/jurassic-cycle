# Design

## Context

См. proposal.md — Why. Точка входа — `GameScreen.tsx`, который сейчас строится как
`header → StatsPanel → game-layout(ActionPanel | LogPanel | StageBar)`. Стили — чистый CSS с
токенами из `theme.css`, эмодзи вместо спрайтов. Данные для аватара уже есть в состоянии:
`game.stageIndex` (индекс в `STAGES`), `game.stats.growth` и константа `GROWTH_PER_STAGE`.

## Goals / Non-Goals

**Goals:**

- Сделать динозавра визуальным центром экрана.
- Связать вид аватара со стадией и ростом, не трогая игровую логику.
- Изолировать визуал в одном компоненте для будущей замены эмодзи на SVG.

**Non-Goals:**

- Замена эмодзи на реальные SVG в этом изменении — только шов для неё.
- Изменение игровых данных, баланса и формата сохранений.
- Добавление новых действий или статов.

## Decisions

- **Отдельный компонент `DinoAvatar`.** Принимает `species`, `stageIndex`, `growth`, `growthMax`.
  Внутри — обёртка, кольцо и «ядро» с эмодзи. Замена эмодзи на SVG = правка только этого
  компонента и его стилей. Альтернатива — оставить эмодзи прямо в `GameScreen`, но тогда шов
  для SVG размывается по разметке.
- **Прогресс-кольцо через CSS `conic-gradient`.** Заполнение = `growth / growthMax`. Это дешевле
  и проще, чем inline-SVG круг с `stroke-dasharray`, и не тянет новых зависимостей. Если позже
  понадобится точная SVG-графика, кольцо тоже переедет внутрь компонента-аватара.
- **Масштаб аватара от стадии и роста.** Базовый размер зависит от `stageIndex`, а прогресс
  внутри стадии добавляет небольшой прирост — так видно «взросление» ещё до смены эмодзи.
  Размер задаётся CSS-переменной на элементе, чтобы значения жили в JSX.
- **Компоновка: центр + две колонки.** `grid-template-columns: minmax(180px, 1fr) auto minmax(200px, 1fr)`
  — состояние слева, аватар в центре, действия справа; журнал и стадии — под всей центральной
  областью. На узкой ширине (`max-width: 980px`) сетка складывается в одну колонку. `StageBar`
  остаётся как текстовый ориентир стадий, но переезжает под аватар, чтобы не дублировать центр.
- **Доступность.** Аватар получает `role="img"` и `aria-label` вида «Тираннозавр, стадия
  Подросток, рост 42 из 100». Кольцо — декоративное (`aria-hidden`), чтобы не дублировать текст.

## Risks / Trade-offs

- [`conic-gradient` требует современного браузера] → целевая аудитория — современные браузеры;
  при отсутствии поддержки кольцо просто не отрисуется, эмодзи и текст остаются читаемыми.
- [Смена раскладки ломает существующие селекторы `.game-layout`] → обновляем CSS согласованно с
  разметкой; на узкой ширине поведение остаётся одноколоночным, как раньше.
- [Дублирование эмодзи (шапка + аватар)] → убираем крупное эмодзи из шапки, оставляя там лишь
  название вида, чтобы центр был единственной точкой внимания.
