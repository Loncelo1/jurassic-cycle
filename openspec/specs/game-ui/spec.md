# game-ui Specification

## Purpose
Описывает, как игровой экран представляет динозавра: крупный центрированный аватар, вокруг
которого сгруппированы состояние и действия, и который наглядно отражает стадию и прогресс роста.

## Requirements

### Requirement: Центральный аватар динозавра

Система MUST отображать динозавра в центре игрового экрана отдельным крупным визуальным
элементом. Аватар MUST быть доступен для вспомогательных технологий через текстовое описание
текущего вида и стадии.

#### Scenario: Аватар находится в центре экрана

- **WHEN** игровой экран отрисован
- **THEN** аватар динозавра является визуальным центром, а панели состояния и действий расположены вокруг него

#### Scenario: Аватар подписан для скринридера

- **WHEN** пользователь использует вспомогательные технологии
- **THEN** аватар сообщает вид и текущую стадию динозавра текстом

### Requirement: Отражение роста в аватаре

Аватар MUST отражать возраст динозавра: эмодзи соответствует текущей стадии из `STAGES`,
а размер аватара растёт вместе с прогрессом роста. Вокруг аватара MUST отображаться кольцо,
заполнение которого равно отношению текущего роста к максимальному росту стадии.

#### Scenario: Эмодзи меняется по стадии

- **WHEN** динозавр переходит на следующую стадию
- **THEN** эмодзи аватара заменяется на эмодзи новой стадии из `STAGES`

#### Scenario: Кольцо показывает прогресс роста

- **WHEN** текущий рост равен `growth`, а максимум стадии — `GROWTH_PER_STAGE`
- **THEN** кольцо вокруг аватара заполнено на `growth / GROWTH_PER_STAGE`

### Requirement: Логическая компоновка панелей вокруг аватара

Игровой экран MUST располагать панель состояния и панель действий рядом с аватаром, а журнал —
в отдельной зоне под центральной областью. При узкой ширине экрана компоновка MUST складываться
в одну колонку без потери доступности элементов.

#### Scenario: Панели расположены вокруг аватара

- **WHEN** ширина экрана достаточна для многоколоночной раскладки
- **THEN** состояние показано слева от аватара, действия — справа, а журнал — под ними

#### Scenario: Узкий экран складывает колонки

- **WHEN** ширина экрана меньше порога многоколоночной раскладки
- **THEN** панели выстраиваются в одну колонку, и все элементы остаются доступны

### Requirement: Готовность аватара к замене на SVG

Визуал аватара MUST быть инкапсулирован в одном компоненте так, чтобы замена эмодзи на
SVG-изображение не требовала изменений в игровой логике и соседних панелях.

#### Scenario: Замена визуала локализована

- **WHEN** визуал аватара заменяется на SVG
- **THEN** изменения затрагивают только компонент аватара и его стили, не игровую логику и не панели
