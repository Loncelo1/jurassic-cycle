# 🦖 Jurassic Cycle — «Юрский цикл»

Пошаговая RPG о выживании и взрослении динозавра. Вдохновлена выживанием из *The Isle*, но
управление построено как в классических пошаговых RPG: каждый ход вы выбираете **одно действие**
(отдохнуть, поохотиться, найти пищу, попить, исследовать), а динозавр тратит запасы организма —
пищу в желудке, воду и энергию — и понемногу растёт.

Цель — провести детёныша через стадии **Детёныш → Молодой → Подросток → Взрослый** и выжить.
Проигрыш наступает при нуле здоровья, пищи или воды.

Игра полностью работает в браузере: **без сервера и без базы данных**. Прогресс сохраняется в
`localStorage`, а также экспортируется и импортируется файлом JSON.

## ✨ Возможности

- **6 играбельных видов** — 3 плотоядных (тираннозавр, велоцираптор, спинозавр) и 3 травоядных
  (трицератопс, брахиозавр, паразауролоф) со своими характеристиками и аппетитом.
- **Пошаговый цикл**: одно действие за ход, день/ночь каждые 8 ходов влияют на охоту и сон.
- **Действия**: отдохнуть, спать, охотиться, искать пищу, пить, исследовать, сражаться, убегать.
- **Система статов**: здоровье, пища, вода, энергия, рост — с полосами и числовыми значениями.
- **Случайные события**: находки, водопои, засады хищников, отравления, ранения.
- **Угрозы**: встреча с хищником переводит игру в режим схватки — сражаться или убегать.
- **Сохранения**: автосохранение, экспорт в файл и импорт из файла.
- **16 модульных тестов** на игровой движок и систему сохранений.

## 🚀 Быстрый старт

```bash
# 1. Установить зависимости
npm install

# 2. Запустить дев-сервер
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173`).

### Сборка и проверки

```bash
npm run build   # проверка типов (tsc) + production-сборка в dist/
npm test        # запуск тестов (Vitest)
npm run preview # локальный просмотр собранной версии
```

## 🎮 Как играть

1. На стартовом экране выберите плотоядного или травоядного динозавра.
2. На игровом экране нажимайте действия на панели слева. Каждое тратит ресурсы.
3. Следите за панелью статов: **пища** и **вода** падают каждые ход, при нуле теряется здоровье.
4. Растите динозавра: отдых, сон и успешные действия дают очки роста.
5. Достигните стадии «Взрослый» — победа. Погибнете — экран итогов с кнопкой «Начать заново».

Советы:

- Плотоядным нужна охота, но она повышена в риске: неудача ранит, а иногда из зарослей выходит
  более опасный хищник.
- Травоядные стабильнее, но должны чаще искать пищу и воду.
- Спинозавр и паразауролоф реже страдают от жажды/голода — хороший выбор для первой партии.
- Ночью сон эффективнее, а охота и поиск — рискованнее.

## 🧱 Стек

| Слой | Технология |
| --- | --- |
| UI | React 18 + TypeScript |
| Сборка | Vite 6 |
| Тесты | Vitest 2 |
| Стили | Чистый CSS с переменными темы |
| Состояние | React Context + `useReducer` |
| Хранение | `localStorage` + экспорт/импорт JSON (без БД) |

Графика намеренно минималистична: вместо спрайтов используются эмодзи и CSS, поэтому проект
не зависит от внешних ассетов и легко запускается где угодно.

## 📁 Структура проекта

```
src/
  game/            Игровая логика (не зависит от React)
    types.ts       Типы состояния, статов, видов, журнала
    balance.ts     Константы баланса, стадии, день/ночь, clamp
    species.ts     Каталог из 6 видов динозавров
    actions.ts     Каталог действий и правила доступности
    events.ts      Таблицы событий, добычи, угроз
    rng.ts         Детерминированный ГПСЧ (seed хранится в состоянии)
    engine.ts      Ядро: createGame, step, availableActions, рост, смерть
    save.ts        Сериализация, localStorage, экспорт/импорт файла
    *.test.ts      Тесты движка и сохранений
  state/
    reducer.ts     Чистый редьюсер и типы действий
    GameContext.tsx Провайдер и хуки useGame / useGameStore
  components/      Экраны и панели интерфейса
  styles/          theme.css (переменные) и global.css (компоненты)
```

Вся игровая механика в `src/game` — это чистые функции над неизменяемым состоянием, что делает
её удобной для тестирования и переиспользования.

## 🌐 Деплой на GitHub Pages

Проект уже готов к публикации. В репозитории есть workflow `.github/workflows/deploy.yml`,
который собирает и выкладывает игру на GitHub Pages.

1. Загрузите код в репозиторий на GitHub (ветка `main`).
2. В **Settings → Pages** выберите источник **GitHub Actions**.
3. Сделайте пуш в `main` — workflow запустит тесты, сборку и публикацию.
4. Игра будет доступна по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

В `vite.config.ts` задан `base: './'`, поэтому сборка корректно работает и в подкаталоге Pages,
и при локальном открытии.
