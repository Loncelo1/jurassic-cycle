# QWEN.md

Контекст проекта для Qwen Code. Читайте этот файл перед изменениями в коде.

## Что это за проект

**Jurassic Cycle** («Юрский цикл») — браузерная пошаговая RPG о выращивании динозавра.
Игрок выбирает вид (плотоядный или травоядный) и ход за ходом выполняет действия
(отдохнуть, поохотиться, найти пищу, попить, исследовать), тратя пищу, воду и энергию
и накапливая рост. Цель — дойти до стадии «Взрослый».

Проект **не использует сервер и базу данных**. Всё состояние живёт в браузере: сохраняется в
`localStorage`, экспортируется/импортируется как JSON.

## Стек и команды

- React 18 + TypeScript, сборщик Vite 6, тесты Vitest 2.
- Стили — чистый CSS с переменными (дизайн-токены в `src/styles/theme.css`), без CSS-фреймворков.
- Управление состоянием — React Context + `useReducer`; игровая логика изолирована от React.

```bash
npm install       # установка зависимостей
npm run dev       # дев-сервер Vite
npm run build     # tsc --noEmit && vite build
npm test          # vitest run
npm run preview   # предпросмотр сборки
```

Всегда перед завершением задачи прогоняйте `npm run build` и `npm test` — они должны быть
зелёными.

## Архитектура и ключевые решения

- **`src/game/` — чистое игровое ядро без зависимостей от React.** Функции работают над
  неизменяемым состоянием и возвращают новое состояние.
  - `engine.ts` — точка входа механики: `createGame`, `step`, `availableActions`, `totalGrowth`.
    Один ход = одно действие + `passiveTurn` (расход ресурсов) + `checkGrowth` + проверка смерти/победы.
  - `balance.ts` — все числовые константы баланса, список стадий, `clamp`, `isNight`, `dayOf`.
    **Меняйте баланс здесь, а не разбрасывая «магические числа» по коду.**
  - `species.ts` — каталог 6 видов; характеристики вида: `maxHealth`, `growthRate`, `huntSkill`,
    `forageSkill`, `appetite`, `thirst`.
  - `actions.ts` — метаданные действий и правило доступности `canAct` (по рациону, стадии, угрозе).
  - `events.ts` — таблицы случайных событий, добычи травоядных и имён хищников.
  - `rng.ts` — детерминированный ГПСЧ. **Состояние генератора (`rngState`) хранится в GameState**,
    поэтому ход воспроизводим из сохранения. Не заменяйте его на `Math.random()` в механике.
  - `save.ts` — сериализация, `localStorage`, экспорт/импорт файла, валидация сохранений.
- **`src/state/`** — `reducer.ts` (чистый редьюсер и типы действий) и `GameContext.tsx`
  (провайдер + хуки `useGame`, `useGameStore`, `useGameDispatch`). Побочные эффекты (запись в
  localStorage) — в редьюсере через функции из `save.ts`.
- **`src/components/`** — экраны (`StartScreen`, `GameScreen`) и панели (`StatsPanel`,
  `ActionPanel`, `LogPanel`, `StageBar`, `SaveControls`, `ResultScreen`).

## Конвенции кода

- TypeScript в строгом режиме; `noUnusedLocals`/`noUnusedParameters` включены — не оставляйте
  неиспользуемых переменных, сборка упадёт.
- Комментарии и пользовательские тексты — на русском. Комментарии пишем только там, где нужно
  объяснить неочевидное (инвариант, хитрость баланса), а не для пересказа кода.
- Игровая логика — чистые функции, без мутаций входного состояния. При изменении вложенных полей
  создавайте новые объекты (`{ ...state, stats: { ...state.stats } }`).
- Новые действия добавляются в трёх местах: `ActionId` и `ACTIONS` в `actions.ts`, обработчик в
  `HANDLERS` в `engine.ts`, при необходимости — числовые константы в `balance.ts`.
- Новые виды — только через `SPECIES` в `species.ts`; UI сам сгруппирует их по рациону.

## Тесты

Тесты лежат рядом с кодом: `src/game/engine.test.ts`, `src/game/save.test.ts`. Конфигурация —
`vitest.config.ts` (окружение `node`, отдельно от `vite.config.ts`, чтобы не конфликтовали версии
Vite). Тесты должны быть детерминированными — передавайте фиксированный seed в `createGame`.

## Стиль интерфейса

Минимализм: тёмная «природная» тема, эмодзи вместо спрайтов, панели-карточки со скруглениями и
мягкими тенями. Цвета и радиусы берутся из CSS-переменных в `src/styles/theme.css`, классы
компонентов — в `src/styles/global.css`. Не добавляйте внешние ассеты и CDN — проект должен
работать офлайн.

## Что нельзя ломать

- Формат сохранений: при изменении структуры `GameState` повышайте `SAVE_VERSION` и обновляйте
  `parseSave`, чтобы старые сохранения не роняли игру.
- Игра должна оставаться работоспособной без сети и без сервера.
- `base: './'` в `vite.config.ts` нужен для корректной работы на GitHub Pages — не меняйте на
  абсолютный путь без причины.
